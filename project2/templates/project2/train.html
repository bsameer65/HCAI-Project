What is λ (lambda)?
λ controls the trade-off between accuracy and simplicity.
λ = 0 → pick the most accurate model, regardless of complexity.
λ = 1 → strongly prefer simpler models, even if less accurate.
The model with the lowest objective score is selected: objective = (1 − accuracy) + λ × normalised complexity

What do these numbers mean?
• Accuracy = percentage of test penguins classified correctly. Higher is better, but a very high accuracy might mean the model is overfitting.
• {% if result.model_type == "dt" %}Leaves{% else %}Non-zero coefficients{% endif %} = the model's complexity. Fewer = simpler and easier to explain.
• Objective = the combined score (lower is better). It mixes accuracy error with λ-weighted complexity.

How does Logistic Regression work?
Logistic Regression assigns a weight (coefficient) to each feature. A larger weight means that feature has a stronger influence on the prediction. Non-zero coefficients are the features the model is actually using — zero coefficients mean those features are ignored. Fewer non-zero coefficients = simpler model.
{% else %}
How does a Decision Tree work?
A Decision Tree splits the data based on feature thresholds, like a flowchart. The number of leaves tells you how many different decision paths the tree has — more leaves means a more complex model.
