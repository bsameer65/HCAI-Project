📈 PDP — {{ feature_name }}

Each curve shows the average predicted probability for one penguin species while {{ feature_name }} is forced to different values across its range. All other features retain their observed values.

How to read the PDP:
• A rising curve means larger feature values increase the model's probability for that species.
• A falling curve means larger values decrease the probability.
• A flat curve means changing the feature does not substantially affect the selected model's prediction.

Decision Tree note: A tree can produce flat or step-like PDP curves because predictions are constant inside leaves and only change when relevant split thresholds are crossed.

📉 ALE — {{ feature_name }}

ALE measures how changing {{ feature_name }} within local feature intervals changes the predicted probability. The accumulated effects are centred around zero.

How to read the ALE:
• Values above zero indicate a positive contribution relative to the average prediction.
• Values below zero indicate a negative contribution.
• A flat ALE means the model has little local sensitivity to that feature.

Derivative interpretation: Logistic Regression is differentiable, so exact derivatives can in principle be calculated. Decision Trees are piecewise constant and have discontinuities at split thresholds, so discretisation or finite differences are used for ALE.
