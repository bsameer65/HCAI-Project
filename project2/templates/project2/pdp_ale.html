PDP vs ALE — what's the difference?

PDP (Partial Dependence Plot) forces a feature to different values across the entire dataset and averages the model response. It is intuitive, but can be misleading when features are correlated — it may evaluate the model on unrealistic feature combinations.

ALE (Accumulated Local Effects) only looks at the model's behaviour in the local neighbourhood of each data point, using small steps within quantile bins. It avoids out-of-distribution extrapolation and is generally considered more reliable when features are correlated.

ALE shows local changes in the model prediction in regions where data actually exists. It is often more realistic than PDP when features are correlated.

📐 Theoretical Note: Why Bin-Based ALE?

Logistic Regression is a smooth, differentiable function — in theory, one could compute the exact partial derivative ∂P(y|x) / ∂xj analytically. However, bin-based ALE is simpler to implement, equally informative in practice, and works directly with predict_proba without needing access to model internals.

Decision Trees are piecewise constant and not smoothly differentiable — their output is a step function that jumps at split thresholds. A derivative-based approach is not defined for them, so discretisation is necessary.

This implementation uses bin-based ALE for both models, giving a consistent, model-agnostic interface that works the same way regardless of which model the user selects on the Train page.

📉 ALE — {{ feature_name }}

Each point shows the local change in predicted probability within the bin around that feature value. Values are centred around zero — positive means the model predicts that species more than average, negative means less than average.

How to read the ALE:
• Above zero → at this feature value, the model predicts that species more often than average.
• Below zero → the model predicts it less often than average.
• The dashed grey line at zero is the reference. A completely flat ALE means the feature has no local effect at any value.
