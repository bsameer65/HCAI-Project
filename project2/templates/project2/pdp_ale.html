What is a PDP (Partial Dependence Plot)?
PDP shows how the model's average predicted probability changes when we force one feature to different values, while keeping all other features at their real observed values.

For example: "On average, what happens to the predicted probability for each species as flipper_length_mm increases?"

How to read it: each coloured line is one species. A rising line means the model becomes more confident about that species as the feature increases. A flat line means that feature doesn't matter much.

Each line shows the average predicted probability for one species as {{ feature_name }} varies from its minimum to maximum observed value. Other features are kept at their real values for each data point.

How to interpret this plot:
• A rising curve for a species means larger values of {{ feature_name }} push the model toward predicting that species.
• A falling curve means larger values make that species less likely to be predicted.
• A flat curve means {{ feature_name }} has little effect on that species' predicted probability.
