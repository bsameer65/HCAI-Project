How should I interpret this?

{% if model_key == "decision_tree" %}
Decision Tree importance measures how strongly each feature contributes to reducing uncertainty when the tree makes its splits.
{% elif model_key == "random_forest" %}
Random Forest importance combines information from many decision trees. Higher-ranked features contributed more strongly across the forest.
{% elif model_key == "logistic_regression" %}
Logistic Regression is explained using coefficient magnitudes. Larger values indicate features with stronger influence on the classification decision.
{% elif model_key == "knn" %}
KNN has no native feature importance. We therefore use permutation importance: each feature is shuffled and we measure how much predictive performance drops.
{% endif %}
Feature importance describes model behaviour and does not imply that a feature causes the predicted outcome.
{% endif %}
