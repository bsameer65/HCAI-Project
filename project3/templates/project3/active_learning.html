Active Learning for Expert Competence Discovery

At this stage, the classifier can use the complete labeled AG News training set, but expert predictions are initially unavailable. The system must therefore decide which articles are worth querying from the expert.

The objective is to discover the expert's competence profile using as few expert queries as possible, while maintaining effective human–AI collaboration.

Query Strategies

Random Sampling

Selects articles uniformly at random. This provides a reference baseline for evaluating whether active selection actually improves query efficiency.

Classifier Entropy

Queries articles where the news classifier has the highest predictive entropy.

This corresponds directly to information-based uncertainty sampling from the lecture.

Competence Uncertainty

Queries articles where the competence model is most uncertain whether the expert will be correct.

This directly targets expert competence discovery rather than only classifier uncertainty.

Hybrid Uncertainty + Diversity

Combines competence uncertainty with diversity from previously queried articles.

The strategy combines information-based and representation-based selection to reduce redundant expert queries.

How to Interpret the Experiment

Random sampling establishes the reference level. If an active strategy reaches similar or better competence prediction with fewer expert queries, it is using human effort more efficiently.

Classifier entropy focuses on difficult classification examples, whereas competence uncertainty explicitly focuses on what is still unknown about the expert. The hybrid strategy additionally discourages redundant queries by favoring diverse articles.
