Human–AI Collaboration

Selective expert intervention can improve system performance while querying the expert for only a small fraction of cases.

Expert intervention is most useful when the classifier is uncertain and the selected expert is competent for the current input.

Key Findings

Strong autonomous baseline

TF-IDF with Logistic Regression achieves high test accuracy, so expert intervention must be selective rather than frequent.

Expert competence is local

The simulated experts perform best only in specific regions of the input space and are substantially weaker elsewhere.

Deferral quality matters

Deferring more examples does not automatically improve the system because harmful and unnecessary deferrals consume human effort or introduce errors.

No universally best deferral rule

Confidence-based and learned competence-aware policies behave differently depending on the selected expert profile.

Active selection can outperform passive querying

Query strategies can improve team performance using only a subset of available expert labels instead of requesting every possible expert response.

Human effort is a resource

A useful human-centric system balances predictive performance against the number of expert queries required.
