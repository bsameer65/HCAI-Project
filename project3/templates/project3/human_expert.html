Human Expert Demo

This optional extension replaces the simulated expert with a real participant. The system selects articles, asks the participant for labels, and estimates an initial human competence profile from the collected responses.

The mandatory experiments remain based on simulated experts for reproducibility. This interface demonstrates how the same workflow can operate with an actual human in the loop.

Why This Extension Matters

The mandatory experiments define expert competence synthetically so that results are reproducible. This extension demonstrates the real human-in-the-loop setting: competence is unknown beforehand and must be inferred from selectively requested human annotations.

An effective query strategy should learn useful information about the human while minimizing the number of interruptions and labels requested from them.
