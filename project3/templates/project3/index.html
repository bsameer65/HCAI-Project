Project Overview

This project investigates how an artificial intelligence system can collaborate with a human expert when classifying news articles from the AG News dataset.

Instead of always making an autonomous prediction, the system can defer selected decisions to an expert. Active learning is then used to learn about the expert's competence using a limited number of expert queries.

The main goal is to learn when the AI should rely on its own prediction and when asking an expert can improve the final decision.

Experimental Workflow

Baseline Classifier Train and evaluate a text classifier using the complete labeled training dataset. Simulated Experts Model imperfect experts with identifiable strengths, weaknesses, and specialist competence regions. Learning to Defer Learn whether the classifier or the expert should handle a particular article. Active Learning Query informative examples to discover the expert's competence efficiently. Human Expert Interactive extension where a real user can classify selected articles and provide expert feedback. Advanced Human–AI Analysis Analyze complementarity, collaboration headroom, confidence calibration, coverage–accuracy trade-offs, active-learning efficiency, and robustness. Results Comparison Compare classifier, expert, deferral, and active-learning performance in one consolidated view.
